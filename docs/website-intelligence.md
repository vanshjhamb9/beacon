# Website Intelligence (GOAP)

Deterministic analyzer over public HTML/text hints (no private scraping).

Detects CMS, framework, hosting, cloud, SSL, mobile, performance, accessibility, SEO, analytics, chatbot, AI widget, booking, forms, CRM, email, marketing automation, support, knowledge base, payments, stack, broken-link hints, security headers, structured data, modernization score, opportunity score.

Engine: `packages/global_opportunity_acquisition/website_analysis/engine.py`
