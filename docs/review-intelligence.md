# Review Intelligence (GOAP)

Deterministic extraction of complaints, missing features, pain points, competitor mentions, and migration opportunities from public review text.

Compliant adapters: SaaSHub / AlternativeTo active feeds; G2 / Capterra / Clutch etc. remain interface-only until licensed/compliant providers are configured.

Engine: `packages/global_opportunity_acquisition/review_intelligence/engine.py`
